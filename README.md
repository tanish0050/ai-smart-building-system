# AI-Powered Smart Building System

An intelligent building management MVP that simulates sensor data and provides automated insights.

## Features
- Real-time simulated energy, temperature, occupancy and humidity monitoring
- Rule-based anomaly detection
- AI-style recommendations for energy optimization and occupant comfort
- Responsive web dashboard
- REST API endpoint at `/api/data`

## Tech Stack
- Python
- Flask
- HTML, CSS, JavaScript

## Run locally
```bash
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000`

## Project Objective
The system solves inefficient building management by monitoring building conditions, detecting abnormal patterns, and recommending actions to improve energy efficiency, safety and occupant comfort.
